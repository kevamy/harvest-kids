# Button
Bouton en pilule pour toutes les actions, d'au moins `touch-min` (56 px) de haut pour être touché sans viser.

- `hk-btn--bleu` (fond `bleu`, texte `blanc`) : l'action principale d'un écran, une seule par écran. Ex. « Enregistrer l'arrivée ».
- `hk-btn--rose` (fond `rose-fonce`) : l'action de sortie, réservée au check-out. Le rose signifie toujours « l'enfant repart ».
- `hk-btn--soleil` : action d'appel ou d'attention (« Appeler le parent »).
- `hk-btn--ghost` : action secondaire ou d'annulation.
- `hk-btn--sombre` : action sur fond clair qui ouvre un outil (scanner).
- `hk-btn--xl` (72 px) : écrans de borne et action unique d'un écran de scan.

Le libellé dit exactement ce qui se passe ; le toast reprend le même verbe (« Arrivée enregistrée »). Pas de flèche ajoutée au texte.
